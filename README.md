一个「活体博物馆」式的 UI 设计风格参考图鉴：**100 种设计风格**在完全相同的组件基线（导航 / 按钮 / 表单 / 卡片）上横向并排呈现，配九维设计档案与可复制的 AI 提示词。

单文件交付 · 无构建依赖 · 离线可用 · WCAG AA 基线。新人接手先读 [HANDOFF.md](HANDOFF.md)。

## 功能地图

### 看 & 学
- **活体展台**——同构组件基线，横向对比最直观
- **九维档案**——理念/字体/配色/间距/形状/阴影/层级/图标/组件规范
- **专业词库**——70 个设计概念（九维档案术语 + **标本语言** + **动效模式**：骨架屏微光/数字滚动/磁吸悬停/视差层叠等）：释义 + AI 关键词 + 参考案例 + 展台与分馆双向互链
- **维度分馆 ×7**——标本墙架构：色彩馆 = 全站去重色卡墙（**312 色**，带 hex 与使用计数，**频次/色相环双排序**，明细含**色相相邻色推荐** + **⚖ WCAG 对比度检查器**：任意前景/背景实时比值、AA/AAA 判定、红绿蓝全色盲模拟预览），字体/形状/图标/组件/动效/阴影六馆 = **76 个可视化类型标本**（动效馆 **24 种运动性格**全部真实播放且遵循减少动态偏好，阴影标本附**一键复制 CSS 配方**）。点击色卡或标本 → 弹层反查采用该做法的全部风格实例；归类为逐风格人工策展映射
- **分馆深链**——`#/color?c=FFD166`、`#/shape?s=pill` 直达并自动打开明细弹层；词库九维术语词条带「◈ 去分馆看标本」互链；混搭提示词内嵌形状/阴影标本跳转

### 选
- **三维筛选**——行业 × 底色 × 情绪下拉组合过滤
- **全文搜索**——覆盖名称/英文/描述/提示词/档案，点击输入框聚焦，`Esc` 清空；也可直接在 ⌘K 面板中搜一切；**拼音检索**——输入 `douyin`、`weixin`、`taobao` 等全拼即可命中对应中文风格
- **⌘K 命令面板**——按 `/` 呼出：一个输入框直达 100 风格 / 18 视图 / 70 词条 / 常用动作（切主题/开混搭/速览墙/调律台），↑↓ 选择 Enter 跳转
- **收藏夹**——localStorage 持久化，「只看收藏」一键过滤；**收藏夹管理面板**：全部收藏一览、跳转、清空
- **最近浏览**——会话内自动记录最近看过的 8 个展台，索引条下方一键回跳
- **A/B 对比**——勾选 2–3 个展台 → 弹层内活体迷你展台 + 六维规格并排
- **▦ 速览墙**——密度切换：完整档案 ⇄ 展台截图墙，点击卡片回到该展台详情
- **🎴 看图猜风格**——闪卡测验：真实展台渲染截图遮名，四选一猜风格；计分 + 连对 + 错题本（localStorage 持久化，30% 概率抽错题复习）
- **🌌 风格星系**——六维基因（形状/字体/图标/组件/动效/阴影）算出 87 星的力导向宇宙：基因相近的风格自然聚簇，瑞士国际主义和德式功能主义是邻居、Y2K 与蒸汽波抱团；拖拽平移 · 滚轮缩放 · 悬停名帖 · 点击直达展台；主色/聚类双着色
- **🎚 色阶派生器**（色彩馆内嵌）——任选展台的底色/主色/深色三点锚定，插值派生 50–950 十一档完整色阶，点击复制色值
- **✦ 手气不错**——随机跳转；收藏满 4 个后只在收藏中抽
- **智能索引条**——滚动时激活药丸自动居中滚入视野，边缘渐隐提示可横向滚动

### 用
- **色卡条**——每展台 4 枚代表色，点击复制色值
- **CSS Token 导出**——一键复制 `:root{}` 变量块（含字体/形状注释）
- **`</>` 代码片段导出**——生成该风格的 `index.html + :root tokens` 起步模板并下载
- **🤖 AI 工具深链**——一键带 prompt 打开 v0.dev / ChatGPT，直接在该风格下生成界面
- **✎ 私人笔记**——每个展台一条本机笔记（localStorage 自动保存），MD 导出时自动附带
- **⧉ 复制 MD 档案**——整份九维档案导出为 Markdown（含年代/适用/参考/AI 提示词/代表色），直接粘贴进文档或 AI 工具
- **📲 PWA 离线安装**——manifest 内联 + Service Worker 缓存（https/localhost 下生效），手机「添加到主屏幕」即成离线风格手册 App；本地 file:// 打印等场景自动静默跳过
- **⎙ 打印单卡**——单独打印某个展台的档案卡（其余内容自动隐藏）
- **♿ 色板体检徽章**——每展台自动两两计算 PAL 四色 WCAG 对比度，头行显示 AAA/AA/AA·大字/不达标 评级（悬停看具体比值）
- **🎚 Token 调律台**——展台一键进弹层：滑杆微调圆角/间距/阴影，活体展台实时响应，导出调后 `:root` 变量块
- **🧭 策展路径**（新视图 `#/paths`）——8 条按真实任务策展的巡展路线（AI 五件套/国潮电商/玻璃谱系/键盘至上…），底部浮条逐台精读
- **🔥 基因热力矩阵**（DNA 视图内）——87×6 六馆归类全览：行=风格、列=维度、同色≈同类基因，点击色块直达标本明细
- **Figma Tokens 导出**——Tokens Studio 插件规范 JSON，粘贴存为 `.json` 直接导入 Figma
- **⤓ W3C Tokens 导出**——W3C Design Tokens 标准格式（`$value/$type/$description` + `$extensions` 结构基因），兼容 Style Dictionary / Tokens Studio
- **词库过滤**——词库页搜索框即时筛选 70 词条（中文名/英文/释义/关键词），空分类自动折叠
- **AI 提示词**——每展台英文 prompt 直接粘贴 Midjourney / Figma AI / v0 / Cursor
- **JSON 出口**——整个数据集复制为 JSON，可二次加工
- **混搭生成器**——随机融合两种风格的 Token，**双舞台实时预览**（A 的场景 × B 的骨架并排渲染），生成英文 mashup prompt；**锁定场景 A / 骨架 B 后重掷**，只换未锁定的一侧；**★ 收藏组合**：保存喜欢的搭配、一键载入、复制分享链接（`?mix=s1+s43` 直达复现）

### 阅读体验
- **智能跳转**——距离感知滚动：目标超过 1.5 屏直接瞬移到位，近距离才平滑滑动；所有入口（索引/进度线/词库互链/分馆实例行/速览墙/键盘 J·K）统一走这一套
- **垂直进度线**——右缘 100 个序号刻度，当前展台高亮拉长，悬停显名称，点击跳转（窄屏自动隐藏）
- **术语速查条**——词库区顶部 70 枚术语药丸，点击滚动到对应词条卡片并高亮闪烁
- **界面分视图**——展馆 / 词库 / 实战 + 7 个维度分馆 + **🕰 年代时间轴**（130 年风格演化按十年聚簇）+ **📱 手机专属区**（100 台**可交互真机**：屏内导航真的切页（首页/发现/收藏/消息/我的五页）、开关真的拨动、▶ 真的播放进度条、像素机十字键真的移动精灵、点按有 Toast 反馈与按压动效——机身形态 5 种 × 导航模式 15+ 种 × 屏内构建器 20 种按风格语义派生；点机身不再跳转，仅底部「展台详情 ↗」离开），顶部标签页切换，哈希路由直达；路由按 DOM 视图容器自动识别，新增分馆零配置；展台深链自动切回展馆定位；J/K 键盘导航仅展馆生效
- **URL 状态同步**——筛选/搜索/收藏条件写入链接参数，分享带参链接即复现视图；**手机区深链** `?focus=sXX` 直达对应真机并高亮
- **社交分享**——og:image 1200×630 分享卡（`og.png`）+ og/twitter meta 全套
- **亮 / 暗双主题**——自动跟随系统，手动切换即记忆（含首帧防闪烁）
- **响应式**——三段断点降级，移动端索引抽屉（☰）
- **无障碍**——skip-link、aria-live 操作播报、焦点环、44px 触控目标、`prefers-reduced-motion` 支持；弹层焦点陷阱（Tab 圈定 + 开启聚焦 / 关闭归还触发点），实例行支持 Enter/空格键盘激活
- **打印友好**——`Ctrl+P` 输出纸质手册（隐藏交互件、保留色彩、防分页截断；分馆自动分章，色彩馆输出为 64px 色卡网格速查表）
- **性能**——`content-visibility:auto` 屏外展台跳过渲染

## 二次开发

数据驱动架构：展台 = `EXHIBITS[]` 数据 + 渲染模板。新增风格只需：

1. 在 `EXHIBITS` 数组追加一条（id/name/en/era/desc/use/avoid/refs/spec/prompt/demoHTML/stageClass/demoClass）
2. 在 `PAL` 补 4 枚代表色、`META` 补行业/底色/情绪标签
3. 如有对应词条，在 `SEE` 词库索引里加反向链接

页首计数、便当盒演示等处同步更新文案即可，渲染引擎零改动。
