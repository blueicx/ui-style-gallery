EXHIBIT 01

瑞士国际主义Swiss / International Typographic Style

网格、无衬线、不对称版式与高饱和单色强调。信息层级全靠字重与留白，装饰归零。

  • 年代1950s 至今
  • 圆角0px（锐利）
  • 阴影几乎不用
  • 配色纸白 + 黑 + 信号红
  • 字体Helvetica 系
  • 适用编辑、作品集、展览
HELVETICA*
WorkAboutContact

Less, but better

网格是骨架，字体是声音。所有层级由字号、字重与对齐完成，不依赖任何装饰元素。

GRIDTYPE
「平面设计的秩序感来自严格的网格系统——12 栏，8pt 基线。」

EXHIBIT 02

新粗野主义Neo-Brutalism

反精致宣言：粗黑描边、硬阴影、荧光撞色。故意「笨拙」，用原始的诚实对抗千篇一律的圆角 SaaS 审美。

  • 年代2016 复兴 / 2022 爆发
  • 圆角0–4px
  • 阴影实色偏移（无模糊）
  • 配色荧光黄 × 粉 × 紫
  • 字体超粗无衬线
  • 适用创意工具、独立产品、活动页
BRUT★L
ShopManifestoCart (3)

No rounded corners.

边框就是边框，阴影就是阴影。设计不装模作样，按钮看起来就像能按下去的实体块。

NEW!-50% OFFFREE SHIP
库存警告：这个卡片还剩 2 件！粗黑边框 + 硬投影 = 可点击的安全感。

EXHIBIT 03

玻璃拟态Glassmorphism

毛玻璃面板悬浮于彩色光斑之上——半透明背景、背景模糊、细白描边与柔和投影共同营造景深。

  • 年代2020–（Apple 引领）
  • 圆角16–24px
  • 阴影大范围柔光
  • 配色深底 + 紫/绿光斑
  • 关键backdrop-filter: blur
  • 适用媒体、金融仪表盘、iOS 风 App
Aurora OS
DiscoverLibraryProfile

Frosted depth, layered light

面板像结了雾的玻璃：底层色彩透出来，前景内容依然清晰可读。层次靠透明度表达。

SPATIALBLUR 16PX
毛玻璃卡片：注意文字与背景始终保持 4.5:1 以上对比度。

EXHIBIT 04

新拟物化Neumorphism / Soft UI

组件从同色背景中「挤出」：双光源投影制造凸起，内凹阴影制造按压。质感极强但对比度低——只适合辅助界面。

  • 年代2019–2021（短命网红）
  • 圆角12–16px
  • 阴影双向（亮 + 暗）
  • 配色单一浅灰紫底
  • 教训对比度不足 AA，慎用于正文
  • 适用智能家居、音乐播放器点缀
Soft UI
RoutineDevices

Extruded from the surface

控件仿佛从面板上压模而出：凸起代表可交互，凹陷代表正在输入或已激活。

SOFTDUAL LIGHT
同色系卡片：注意它必须依靠阴影而非颜色来区分层级。

EXHIBIT 05

暗色专业Dark Professional / SaaS Dark

当代开发者工具的主流形态：近黑分层表面、低饱和灰阶文本、单一品牌强调色、克制的辉光反馈。

  • 年代2016– 主流化
  • 圆角8–14px
  • 阴影深色柔光 / 辉光
  • 配色#16181d 底 + 蓝强调
  • 要点层级靠表面明度差
  • 适用IDE、监控台、开发者平台
⌘ Deploy
PipelinesLogsSettings

Surface hierarchy, not decoration

暗色模式下不用纯黑：#16181d 打底，逐层提亮表面区分层级。强调色只给主操作。

● RUNNING✓ HEALTHY
构建 #4821 — 12 个服务全部通过健康检查。暗色界面文本不低于 #e6e8ee。

EXHIBIT 06

终端极客Terminal / Hacker Aesthetic

等宽字体、磷光绿、方括号与命令行隐喻。信息密度极高，装饰为零，一切皆文本。

  • 年代1970s 血统 · 永恒小众
  • 圆角0px
  • 阴影无
  • 配色近黑底 + 磷光绿
  • 字体JetBrains Mono 全等宽
  • 适用CLI 工具、开发者文档、黑客松

EXHIBIT 07

黏土拟物Claymorphism

软糖般的立体感：大圆角 + 双层投影（外柔光 + 内高光）+ 糖果色渐变，像捏出来的黏土玩具。

  • 年代2021–2023
  • 圆角18–32px
  • 阴影外柔影 + 内高光双层
  • 配色蜜桃 × 樱粉 × 香芋紫
  • 要点比新拟物对比度更好
  • 适用儿童产品、NFT、轻松社交 App
🧸 Plushly
玩具屋朋友

Soft like a marshmallow

按钮像可以捏的果冻：按下去会回弹。圆润不是装饰，是「无害」的信号。

SOFT 3DCANDY
黏土卡片：外层柔影撑起体积，内层高光模拟顶光，双层缺一不可。

EXHIBIT 08

极简编辑Minimal Editorial

数字杂志排版：衬线大标题、细分割线、大量留白。几乎不使用阴影与色块——层级全靠字体排印本身。

  • 年代永恒（报纸血统）
  • 圆角0–2px
  • 阴影无（用细线分隔）
  • 配色暖白 + 墨黑双色
  • 字体衬线标题 + 无衬线 UI
  • 适用媒体、博客、高端品牌官网
The Review
文化科技专栏

Typography is the interface

当排版足够好，就不需要任何装饰。标题用衬线体建立权威感，正文保持 65–75 字符的舒适行长。

ISSUE 42长文
阅读进度条是本页唯一的动态元素——克制本身就是一种奢华。

EXHIBIT 09

复古未来主义Retro-Futurism / Outrun Interface

80 年代科幻控制台的想象：深蓝底、霓虹辉光、发光描边。像《银翼杀手》里按下去会「嘀」一声的面板。

  • 年代1982 想象的 2019
  • 圆角4–10px
  • 阴影彩色辉光 box-shadow
  • 配色深钴蓝 × 电光紫
  • 要点text-shadow 制造 CRT 泛光
  • 适用游戏、音乐、主题活动页
◈ NEXUS-7
主控导航能源

SYSTEM ONLINE_

每个控件都连着背光：按钮按下时泛起电弧，进度条是反应堆功率。界面即驾驶舱。

PWR 87%LINK OK
// 反应堆输出稳定 —— 辉光强度与状态严重性挂钩，别让整个界面都在发光。

EXHIBIT 10

便当盒网格Bento Grid / Bento Box Layout

信息装进大小不一的圆角格子里，像日式便当：一屏之内高密度陈列，每格自成一体又互相咬合。

  • 年代2022– 爆红（Apple 发布页带火）
  • 圆角16–24px
  • 阴影极浅或无，靠留白分隔
  • 配色白/浅灰底 + 少量强调格
  • 要点跨行跨列制造视觉锚点
  • 适用个人主页、产品特性总览、仪表盘

EXHIBIT 11

材料设计Material Design 3

Google 的物理隐喻体系：纸片层叠、真实投影、药丸形按钮、动态色彩。规则最完备、生态最成熟的设计语言。

  • 年代2014 / M3 于 2021
  • 圆角8–28px（形状分级）
  • 阴影高度系统（elevation 0–5）
  • 配色种子色生成 tonal 调色板
  • 字体Roboto / Noto 全家桶
  • 适用Android、跨平台一致性问题
Material You
首页资料库

Paper with physics

表面有「高度」：越重要的浮得越高，投影越明显。FAB 药丸形是可发现性的妥协。

ELEVATION 2TONAL
填充式文本框：淡紫底色提示可交互区域，底部 2px 线条承载焦点态。

EXHIBIT 12

Y2K 千禧赛博Y2K / Cyber Millennium

千禧年的乐观科技幻想：铬金属渐变、糖果紫粉、网格地平线、半透明「果冻」质感。复古但毫不怀旧——它相信未来会很闪。

  • 年代1997–2004 / 2022 复兴
  • 圆角12–20px（药丸/气泡）
  • 阴影彩色投影 + 内高光
  • 配色电紫 × 桃粉 × 冰蓝
  • 要点金属渐变 + 白描边 = 铬感
  • 适用潮流品牌、音乐、虚拟偶像

Welcome 2 the future!

拨号上网时代的太空梦：所有东西都像塑料玩具——半透明、发光、摸起来咔哒作响。

★ NEW ★MP3 铃声
铬金属面板：白描边 + 多段浅色渐变 + 彩色外影，三层叠加才有「液态金属」感。

EXHIBIT 13

有机柔和Organic Soft / Wellness UI

健康与可持续产品的语言：鼠尾草绿 + 奶油底、不对称大圆角（像被风吹圆的鹅卵石）、低刺激的动效与插画。

  • 年代2020– 与 wellness 浪潮同步
  • 圆角20–32px 不对称分布
  • 阴影极浅漫射，无锐利边缘
  • 配色鼠尾草绿 × 燕麦奶油 × 陶土橙
  • 要点圆角方向暗示流动感
  • 适用冥想 App、医疗健康、环保品牌
🌿 Fern
今日花园睡眠

Breathe in, breathe out

界面应该像一次深呼吸：没有刺眼的对比，没有急促的动画。圆角的不对称让视线自然流动。

平静专注 25min
本周情绪曲线平稳向上——绿色系将压力感知降到最低，留白即疗愈。

阅读方式：每个展台左侧是风格档案（年代 · 圆角 · 阴影 · 配色策略 · 适用场景），右侧是该风格渲染的同一组件基线。所有文本对比度均满足 WCAG AA；动画已适配 prefers-reduced-motion。
